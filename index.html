03 COLLECTION PROCESS

One start.
Self-healing checkpoints.

The companion handles routine recovery after launch. Keep the computer awake and the companion running; intervene only if Vaahan presents a CAPTCHA, rate limit, access restriction, or a genuine dashboard redesign.

01 / CONNECTStart the companion

Run the free local companion and confirm the secure connection indicator.

02 / VALIDATEReview the estimate

The planner includes expected refresh time and blocks plans above 1,00,000 rows.

03 / COLLECTVerified refresh

Chrome or Edge waits for Vaahan's actual report response instead of relying on a fixed timer.

04 / RECOVERRetry & adapt

Temporary failures retry twice from a de-duplicated checkpoint; slow responses increase the pause.

05 / EXPORTLive ETA & download

The monitor learns from observed speed and exports complete or partial local results.

Manual action is intentionally retained for safeguards.The tool never retries CAPTCHA or rate limits, bypasses access controls, keeps a stopped PC awake, or guesses after a genuine Vaahan page redesign.

03 DISTRIBUTED ARCHITECTURE

Hosted planning.
Minimized local collection.

Free public hosting cannot safely operate a persistent browser. The planner lives online; a token-protected companion runs a normal Chrome or Edge window minimized on each visitor's computer, keeps data local, and pauses on access challenges.

06 SAFETY PROTOCOL

Designed to
back off.

01 / ACCESS

No evasion

No proxy rotation, fingerprint spoofing, CAPTCHA solving or login bypass.

02 / PRESSURE

Adaptive request load

One report at a time. Slow Vaahan responses add up to 45 seconds to subsequent pauses.

03 / CONTINUITY

Idempotent checkpoints

Interrupted writes are reconciled and duplicate analytical rows are removed before collection continues.

04 / RECOVERY

Safe self-healing

Only temporary technical failures retry. CAPTCHA, rate limits and structural changes remain paused.
